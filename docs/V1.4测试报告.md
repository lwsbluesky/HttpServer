# HttpServer V1.4.0.0 开发与测试报告

日期：2026-11-13  
测试平台：Windows 11 x64、Python 3.10.11、Edge/Chromium  1.4.0.0

## 本版交付

- 单文件、多文件和目录上传；浏览器显示传输进度和完成/失败状态，同名策略支持提示、自动改名、覆盖和跳过。
- 上传以同目录临时文件接收，长度核验并同步落盘后提交；单文件不超过 1 GiB，同时最多接收 4 个上传。
- 新建目录、重命名、移动、复制、删除；批量删除和移动；批量项目 ZIP 下载。
- 回收站保留原路径、操作者和时间，支持恢复，默认 30 天后清理。
- 服务端分页和名称、大小、修改时间、类型排序。
- EXE 版本号和 FastAPI 健康状态统一为 1.4.0.0。

## 测试结果

| 检查 | 结果 |
| --- | --- |
| V1.3 安全/稳定性 API 回归 + V1.4 文件管理 API 测试 | 87 通过，1 跳过，0 失败（88 项） |
| Python 编译、JavaScript 语法、Git diff whitespace 检查 | 通过 |
| Edge 浏览器源代码进程流程 | 通过：首次改密、Unicode 预览、断网恢复、上传进度/完成、批量 ZIP、管理权限、390px 手机布局、guest 下载、注销 |
| Edge 浏览器打包 EXE 流程 | 通过：与源代码浏览器流程相同，0 个页面 JavaScript 错误 |
| 源代码和 EXE 真实进程负载 | 通过：2 个并行 128 MiB ZIP + 50 个普通请求；普通请求最大响应分别约 0.204 秒和 0.220 秒，繁忙任务明确返回 503 |
| EXE 重启验证 | 通过：重启后旧会话令牌失效，数据库配置保留 |
| 5 秒持续访问与临时文件回收检查 | 通过：请求均为 200，临时目录无残留；进程线程/句柄/内存增长均在脚本阈值内 |

跳过项：Windows 符号链接越界测试因当前账号没有创建符号链接的权限而跳过；Windows Junction 路径用例通过。pytest 有一条 Starlette TestClient 关于 httpx 兼容方向的弃用提示，不影响用例结果。

长稳限制：本次真实进程持续访问为 5 秒，另有逻辑时间清理回归；没有执行策划书要求的 72 小时墙钟长稳测试。短测结果不能代替 72 小时验收。
